# 💱 Currency Converter

A simple and responsive Currency Converter web application built using **HTML, CSS, and JavaScript**. It allows users to convert an amount from one currency to another using real-time exchange rates fetched from a public API.

## 🚀 Features

* Convert between multiple currencies (USD, INR, EUR, GBP, JPY, AUD, CAD)
* Fetches live exchange rates using an Exchange Rate API
* Automatically updates country flags based on the selected currencies
* Responsive and clean user interface
* Input validation for invalid or empty amounts
* Displays the converted currency value instantly

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Fetch API
* Font Awesome
* Flags API
* Exchange Rate API

## ⚙️ How It Works

1. Enter the amount to convert.
2. Select the source currency.
3. Select the target currency.
4. Click **"Get Exchange Value"**.
5. The application fetches the latest exchange rate and displays the converted amount.
6. Country flags automatically change when different currencies are selected.
